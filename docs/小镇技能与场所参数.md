# 小镇场所、课程与技能

点击室外地图上的建筑，展开对应服务可查看和修改参数。模拟运行或身份选择期间只能查看，暂停后可保存；回放只读。修改作用于新活动，已经开始或在前往途中的活动沿用已接受的费用和时长。参数随当前世界存档与录制帧保存，新世界恢复默认值。

## 场所分工

- 咖啡馆：喝咖啡、看书，恢复心情和精力，不恢复饱食度。
- 饭店：吃饭恢复饱食度；室友共同用餐时增进彼此好感，单人用餐不凭空增加关系。
- 学校：学习六门基础课程，抵达并开始学习时一次交清学费，之后不按时间扣费。经验按实际学习时间累计，中断保留已学经验，学费不退。
- 诊所、饭店、事务所：提供不同岗位；基础岗位不要求技能，可先挣钱交学费，进阶岗位要求相关技能等级。
- 商店：鲜花默认12元、盆栽20元、零食杂物6元、私家汽车1000元。点击商店可查看和修改售价，模型决策与购买结算读取同一价格。

一刻为10分钟，一小时为6刻。工资按实际已工作的时间计算，途中中断不支付未来工资。采用累计应付金额减去已付金额的方式按分结算，避免每刻分别舍入导致时薪出现偏差。

所有职业分为一级、二级。二级技能门槛更高，最低班次约为一级的一半（取整为10分钟），基础时薪为一级的1.5倍；旧一级岗位编号保持不变。相关技能每级减少岗位精力消耗2%，最高10%，计算式为“基础精力率×(1−0.02×技能等级)×实际小时数”。

所有职业默认每小时获得3点对应技能经验，教师每小时6点。每门课程的“该学科普通工作经验率”统一控制所有关联职业，教师始终按两倍计算，不单独配置，以免调整后失去两倍关系。经验只在实际工作时结算，路途和等待不增长；提前中断保留已获得经验，5级封顶。教师必须具备任教学科3级，二级教师需要5级，学校岗位不生成额外游戏参与者。工作经验、工资及参数合同随存档恢复，已开始工作沿用原经验率，防止参数修改改变正在执行的合同。

## 生活收益

- 医学：1级起可在家为自己或室友治疗，最高可处理与等级对应的病重程度；每小时恢复生命16×医学等级，治疗室友时对方好感每小时增加4×医学等级。累计有效治疗30分钟可治愈能力范围内的疾病。目标必须留在家中且在身边，超出能力的病情仍应去诊所。
- 烹饪：做饭及吃这批自制餐时，每级在每刻额外增加0.8饱食、0.3精力和0.3心情。公共餐保存最后一批饭的烹饪品质，室友也能享用。
- 经济学：1级解锁自己的电脑上的虚拟股票交易，使用小镇综合指数，初始10元一份；游戏时间每小时价格小幅随机变化，可涨可跌，无杠杆、不可卖空。成交按当时价格结算，余额或持仓不足整笔失败。持仓、成本、成交记录和指数状态均进入存档。
- 计算机：解锁软件开发岗位，电脑游戏每小时额外增加1.2×等级的心情。
- 理学：解锁科研助理岗位，并减少学习精力消耗。
- 文学：解锁文字编辑岗位，咖啡馆阅读每小时额外增加1.2×等级的心情。

技能、经验和持仓属于角色的长期状态，独立于普通事件记忆。角色自主记录的电脑文档仍按原规则保存，用户只读。

所有活动的数值收益均为“收益率×实际活动时间”，每10分钟结算一次。例如共同喝咖啡每小时增加8好感，共同用餐每小时增加4好感；一起喝30分钟咖啡双方各增加4好感。学习经验、工资、恢复、精力消耗和装饰收益同样按实际时间累计，达到属性上限时封顶。学费、商品和交易本金属于一次性付款，不按时间重复支付。

## 验证思路

验证不仅检查界面是否出现按钮，还检查实际因果：走到学校开始学习才一次扣清学费，经验随时间增长，中断保留经验；缺少技能不能接高级岗位；中断只保留已挣工资；咖啡不补饥饿；共同喝咖啡和用餐对双方按时间产生好感；医疗和料理对数值产生效果；存档能恢复进行中的合同和市场状态。建筑修改在服务端再次检查运行状态，因此绕过页面也不能在模拟过程中改数值。
