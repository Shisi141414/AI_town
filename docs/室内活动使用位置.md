# 室内活动使用位置

根据提供的红框示意，将活动目标从整片房间改为具体家具使用位。坐标是地图格坐标，从0开始；家具绘图以每格16像素为基准。

| 活动 | 指定位置 |
|---|---|
| 做饭 | 灶台右侧的两处空位：(13,3)、(13,4) |
| 吃饭 | 餐桌四把椅子：(10,11)、(13,11)、(10,14)、(13,14) |
| 电脑、电脑游戏、虚拟指数交易 | 各自卧室的电脑桌前；卧室05按调整后的桌子单独设置 |
| 睡觉 | 自己床的中部；五张床使用相同的相对位置 |
| 床上亲密互动 | 发起者床的两个相邻位置；双方分别前往，不共享同一格 |
| 洗澡 | 卫浴1的(13,23)、卫浴2的(17,23) |
| 看电视、客厅游戏 | 沙发上的四个座位：(20,8)、(22,8)、(21,8)、(23,8) |
| 晒太阳、阳台休息 | 阳台东南空位：(23,23)、(24,23)、(22,23)、(23,24) |

多位置活动优先选择空闲使用位，并在前往途中预留该位置。全部被占用时等待，不在附近地面提前结算收益，也不重复支付费用。电脑始终使用自己的，睡眠始终回自己的床。

碰撞分成“普通通行”和“使用家具”：床、餐椅、沙发等仍阻挡普通通行；只有前往或使用该家具的角色，可以进入对应的少量交互格。其他角色仍不能占用该格，也不能借此穿过整片家具。使用结束后，角色从家具使用位回到附近空闲地面；所有床、椅子和电脑都遵循同一规则。

模型可给原有love活动填写location=bed，选择在床上亲密相处；location=here维持原地互动。床上邀请沿用双方好感要求，且应答者必须空闲；双方走到相邻位置后才开始互动，不增加额外游戏参与者。

进行中的使用位置、预留和床上双方的前往状态进入完整存档。读取旧档时，缺少使用位的活动先前往正确位置，再继续剩余活动；不重复收费，也不重置剩余时长。
