📖 AI 小镇 · 使用指南

这是什么？

一座由 AI 居民自主生活的合租之家 + 小镇。每个居民由一个大模型扮演，共享同一份提示词，但拥有各自的记忆、数值状态和人际关系——所以他们会表现出不同的性格。

30 秒上手

① 点顶部的 ▶ 开始，居民们先给自己起名字（若已配置 API）；② 看着他们吃饭、上班、打游戏、交朋友；③ 中途随时可 ⏸ 暂停 / ⏭ 单步 / 调速 / ⟲ 重置。

两个场景

地图上方有两个标签页：室内·合租之家（5 间卧室、客厅、厨房、餐厅、两个卫生间、洗衣区、大阳台）和室外·小镇（商店、公园、办公楼、电影院、健身房、医院等）。居民从东侧大门出入；两个场景用不同比例尺渲染。

接入大模型

不配置 API 时居民由内置规则引擎驱动（也能玩）。想要「真 AI」：

① 侧栏 API / 模型 → 新增档案：填 Base URL、API Key，选上游格式；
② 点 📋 获取模型列表 直接拉取该网关可用模型，点选即可，不用手填；
③ 保存后点「测试」验证连通，然后「启用」；
④ 在「玩家模型绑定」里为每个居民先选择 API 档案、再点「载模型」挑选具体模型——不同居民可以走不同网关、用不同模型（比如两个走 A 网关用 DeepSeek / GLM，三个走 B 网关用 Qwen / ERNIE / MiniMax），观察他们的性格差异。

社交机制

居民一起打游戏、吃饭、工作有协同加成（效果随人数提升），但好感度会调制加成——关系差的人一起做事反而互相拖累。每次互动后，模型自己决定好感变化多少（-5~+5），送鲜花/盆栽能大幅提升好感。在「关系网」面板可以看到实时的好感网络图。

生活循环

饱食度会持续下降，归零开始掉血；血量归零会被送医并扣 30 元；没钱要去办公楼/田地/施工地打工；睡觉恢复精力，夜间睡眠效果更好。居民可以去商店买鲜花💐/盆栽🪴布置自己的房间或公共区域（持续提升心情），也可以送给心上人。

观察工具

居民面板：每个人的数值、当前活动、持有物品；关系网：好感网络图；事件：全部日志（按天/类型/关键词过滤，含 AI 决策理由和对白）；设置：编辑统一提示词、读任意居民的记忆流。

省 token 技巧

「聊天时生成对白」关闭后，对话改用内置文案，只剩决策调用 LLM。速度调快（8x）会让单位时间内的决策更密集，token 消耗也随之上升。
