📖 AI 小镇 · 使用指南

这是什么？

一个探索不同模型在相同提示词下可能产生性格自然涌现的项目。我们构建了一个小镇场景，将至多 5 位居民（默认 3 位）置于其中，给他们相同的提示词、几乎完全对称的机会和资源，完全由他们自行决定如何生活与交流。你可以给每个居民接入不同的模型，观察每个模型在长期生活中表现出的截然不同的兴趣与性格。

快速上手

① 选择居民数量：侧栏「设置」→ 居民管理，＋ 入住小镇 添加（至多 5 位，可移除）；默认勾选「开局由模型自选姓名、性别与颜色」；

② 新建档案：侧栏「模型」→ 新增 API 档案，填 Base URL、API Key、上游格式，点 📋 获取模型列表 拉取可用模型，保存后「启用」；

（您的 API Key 只在本地使用，不会被上传网络）

③ 载入模型：在「玩家模型绑定」里为每位居民先选 API 档案、再点「载模型」挑具体模型——不同居民可走不同网关用不同模型，「保存绑定」；

④ 开始：点顶部 ▶ 开始，居民们先自选身份，然后开始生活；

⑤ 观察：在侧栏各面板看数值、关系、事件与决策理由；

⑥ 控制：随时 ⏸ 暂停 / ⏭ 单步 / 调速（0.5x～8x）/ ⟲ 重置。不配置 API 也能玩——居民由内置规则引擎驱动。

场景

使用左上角标签切换两个场景：

  • 室内·合租之家——5 间卧室、客厅、厨房、餐厅、两个卫生间、洗衣区、大阳台；
  • 室外·小镇——商店、学校、办公楼、诊所、咖啡馆、饭店、电影院、健身房、池塘等。

居民从东侧大门出入，室外建筑点击可查看和调整场所机制。

观察面板

  • 居民：每人卡片显示
    • 四维数值（生命/饱食/精力/心情）、金钱与拥有物品
    • 当前活动、所在位置、健康状况
    • 身体节律（需在设置打开生理周期）
    • 所学技能、电脑记录、资金往来
    • 提示词与回复、当前接入模型
    • 点「记忆提取」可查看模型当前记忆
    选中居民卡片后，最下方还可查看「室友的出行计划」（出行方式与车辆）。
  • 关系网：实时好感网络图和当前关系列表（谁与谁恋爱/挚友，第几天）。
  • 事件：全部日志流水，可按类型、天数范围、关键词过滤，可切换「游戏事件」和「提示」。
  • 模型：API 档案管理（新建/测试/启用）、玩家模型绑定。
  • 设置：系统提示词编辑（保存/恢复默认）、「聊天时生成对白」开关、「生理周期」开关、决策温度与超时、居民数量管理。
  • 存档：保存当前世界（含记忆、对话、进度、提示词与绑定）为存档；点击存档可选「从此处继续」（创建副本）、「回放」（顶部进度条调进度、暂停与倍速）、「重命名」、「收藏」与「删除」。
  • ⚙ 机制（顶栏）：运行中只读，暂停后可改数值规则、营业时间、活动参数及提示词。右上角可保存机制记录、打开旧记录或批量删除；应用失败也会留下带原因的记录。

游戏机制

身体状态：生命、饱食、精力、心情四项持续消耗；饱食归零掉血、心情长期低落掉血、疾病发作掉血——每种原因首次扣血时居民会被告知原因。

饮食：吃饭四途——在家做饭、吃随身饭菜、下馆子（10 元）、请室友送饭；饱食达上限（默认 95）后任何用餐被拒。做饭需先在商店买食材，30/45/60/80 分钟产出 1/2/3/4 份；多余食材（≤12 份）与饭菜（≤4 份）放厨房冰箱，冰箱饭菜保质期 ×3。

睡眠：睡觉恢复精力，夜间效果更好。

出行：步行 1 格/刻、骑行 4 格/刻（消耗饱食精力），汽车最高 12 格/刻；走路不检测居民间碰撞，设施使用位由决策层分配。全镇一辆共用汽车，商店可购车；学校完成驾照课才能驾驶，无驾照可乘车（司机车位两格内可搭乘，另载至多 3 人）。

社交：对话需同一地点，电话可跨地点（话费拨打者付）；一起吃饭/工作有协同加成，好感调制加成；每次互动后模型自定好感变化（-5～+5）；鲜花/盆栽大幅提升好感，也可布置房间。

正式关系：恋爱、挚友经「提出 → 12 小时内接受」建立（需当面）；任一方单方面结束即生效，结束后双方各一次 ±5 好感结算。约会和互动需对方同意（回应同行动即同意），同意后两人共同进行；需好感互达 55 或已是恋爱关系。

生理周期（设置可开关）：5 天一轮，每人开局随机相位。男性紧张度渐升、消耗最高 ×1.4，卫生间「自行解决」或亲密互动后释放；女性第 1 天生理期随机轻微掉血（不打断活动），第 4～5 天黄体期渴望恋爱互动，未满足心情消耗 ×1.5。

技能与工作：学校学技能（100 经验/级，最高 5 级），技能解锁更高岗位；职业分一二级，工资按实际工时支付，工作积累经验；诊所 24 小时营业；池塘钓鱼游泳、花园园艺，收益按活动时长算。

经济与电脑：商店购物；学经济学（≥1 级）可在电脑上看行情交易股票；电脑可搜索资料并写入记忆、玩游戏；居民间可转账、借钱。居民生命值极低触发急救，急救收取较高费用；费用不足时先向室友借钱，金额仍不足则退还借款并进行基础治疗，收取基础治疗费用。

记忆：每人记忆分三级，越高级越持久（约 10:1 晋升）；居民面板可读完整记忆流。
